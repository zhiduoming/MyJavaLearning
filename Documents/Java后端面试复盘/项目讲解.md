### 项目1 分钟讲解

我的项目叫 Uni_Tour， 是一个面向高校参观和择校信息查询场景的校园导览系统，围绕高校基础信息、校区差异、校园 POI 和用户经验分享，帮助用户更直观地了解校园环境和生活信息。

技术上使用了Springboot，Mybatis，MySQL，Redis，JWT，文件上传使用阿里云 OSS，并部署到了自己的云服务器上。整体采用 Controller、Service、Mapper三层架构，以及统一 Result 结果返回还有全局异常处理。

目前主要实现了用户注册登录，JWT 鉴权，高校列表查询，高校详情查询，校区 POI 展示，评价模块，评价模块有评价发布、回复、点赞功能，OSS 图片上传功能，然后使用使用了 Redis 缓存了高校详情和注册时需要的验证码。

通过这个项目，我重点熟悉了后端接口开发、数据库表设计、MyBatis xml、以及 Redis 的基本使用和项目部署的流程。
